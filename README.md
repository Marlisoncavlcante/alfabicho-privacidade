# Política de Privacidade — AlfaBicho

Página pública da política de privacidade do app **AlfaBicho: O Safári das Palavras**
(`br.com.alfabicho.app`), exigida pela Google Play.

🔗 **https://marlisoncavlcante.github.io/alfabicho-privacidade/**

## Não edite o index.html aqui

Esta pasta é gerada por `ferramentas/publicar-privacidade.js` a partir de
`loja/privacidade.html`. Para alterar o texto:

```powershell
# 1. edite loja\privacidade.html
# 2. regenere:
node ferramentas\publicar-privacidade.js
# 3. publique:
cd loja\site-privacidade
git add -A
git commit -m "Atualiza a política de privacidade"
git push
```

O GitHub Pages republica sozinho em cerca de 1 minuto.
